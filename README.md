# 이벤트 관리 - 광고 관리 시스템

광고 및 이벤트를 관리하는 웹 인터페이스입니다.

## 기능

- **헤더**: 잔액 표시, 충전 버튼, 사용자 정보, 이벤트 등록
- **탭**: 광고 / 소재 탭 전환
- **필터**: 광고 상태, 카테고리, 언어, EID/이벤트명 검색
- **광고 테이블**:
  - 광고 상태 (라이브, 대기, 중지, 잔액부족, 기간종료)
  - 검수 상태 (승인, 반려, 검수중)
  - 광고 노출 토글
  - EID, 카테고리, 이벤트 정보
  - 가격, 신청 수, 후기
  - 외부 노출 설정, 히스토리, 복제, 수정 버튼
- **페이지네이션**: 페이지 이동, 항목 수 선택

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 `http://localhost:5173`에서 실행됩니다.

## 빌드

```bash
npm run build
```
